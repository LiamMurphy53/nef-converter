# Changelog

## 1.0.0

- Batch conversion of Nikon NEF files to full-resolution JPEG or 16-bit PNG.
- Drag-and-drop and file picker; adjustable JPEG quality.
- Local RAW development with Apple's Core Image decoder.
- Original photos preserved and existing exports never overwritten.
- Per-file error messages and stop-after-current control.
- Universal Mac app containing Apple Silicon and Intel builds.

The download is locally signed, but is not Apple Developer ID signed or notarized. Camera and compression compatibility depends on macOS. Windows and Linux are not supported.
